# Dev flags (Claude Code Tray)

The catalogue is **[`reference/dev-flags.md`](../../../reference/dev-flags.md)**. Read it there, and
edit it there: a new flag gets its entry in that file, and `--selftest` fails a flag the sources accept
that the catalogue does not name.

It lives outside `.claude/` because Claude Code asks for approval on every edit under that folder, and
a new flag means an edit to it. This skill only points to it.
